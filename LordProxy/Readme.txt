The directory contains: 
  1. Built LORD (.jar), 
  2. LORD proxy written in python
  3. Example python code files to run LORD:
      - run_lord.py:  this is a tutotial to run LORD for cross-validation
      - info_base_usage: this is a tutorial to use the data structure used by LORD for querying the frequency of a set of feature values (the support count of an itemset)
      - run_lord_export_onehot.py: this is a tutorial to run LORD for cross-validation and export the rule set and train/test dataset in form of onehot encoding (each distinct feature value is reppresent in a one-hot code)

Package dependencies:
  1. Be sure that Java 1.8 or newer be installed on your machine
  2. Python package: jpype, sklearn, pandas

Execute the tutorial as a normal python script
